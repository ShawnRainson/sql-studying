Есть данные → они находятся в таблицах → SQL позволяет нам задавать базе вопросы и изменять данные.

1. Что такое SQL?

SQL (Structured Query Language) — язык, с помощью которого мы работаем с реляционными базами данных.

Например, у нас есть интернет-магазин и таблица пользователей:

users

id | name  | age | city
---+-------+-----+----------
1  | Alex  | 25  | Moscow
2  | Ivan  | 31  | Kazan
3  | Maria | 22  | Moscow

Мы можем спросить базу:

Покажи всех пользователей.

SELECT *
FROM users;

Или:

Покажи только имена.

SELECT name
FROM users;

Или:

Покажи пользователей старше 25 лет.

SELECT *
FROM users
WHERE age > 25;

То есть SQL — это прежде всего способ описать, какие данные нам нужны и что с ними сделать.

2. SQL и PostgreSQL — не одно и то же

Это очень важно понять с самого начала.

SQL

Это язык.

Пример:

SELECT name
FROM users;
PostgreSQL

Это система управления базами данных (СУБД), которая умеет понимать SQL и работать с данными.

Упрощённо:

          SQL
           ↓
     "Покажи пользователей"
           ↓
      PostgreSQL
           ↓
        users
           ↓
        данные

Можно сказать:

SQL — язык, PostgreSQL — программа, которая этот язык выполняет.

Есть и другие СУБД:

PostgreSQL
MySQL
Microsoft SQL Server
Oracle Database
SQLite

Но SQL является общим языком для работы с реляционными БД, хотя у каждой СУБД есть свои особенности.

3. Что такое база данных?

База данных — это организованное хранилище данных, с которым может работать программа.

Например, интернет-магазин может хранить:

users
products
orders
order_items
payments

Условно:

DATABASE
│
├── users
├── products
├── orders
├── order_items
└── payments

Важно:

база данных — это не просто одна таблица.

Она обычно состоит из множества связанных таблиц.

4. Что такое таблица?

Таблица очень похожа на привычную Excel-таблицу.

Например:

users

id | name  | age | city
---+-------+-----+----------
1  | Alex  | 25  | Moscow
2  | Ivan  | 31  | Kazan
3  | Maria | 22  | Moscow
4  | John  | 28  | Berlin

У таблицы есть:

Столбцы
id
name
age
city

Их ещё называют columns.

Строки
1 | Alex  | 25 | Moscow
2 | Ivan  | 31 | Kazan
3 | Maria | 22 | Moscow

Их называют rows.

5. Что такое поле?

Например:

3 | Maria | 22 | Moscow

Значение:

Maria

находится в столбце:

name

Конкретное значение в пересечении строки и столбца часто называют значением поля.

Пока достаточно понимать:

column = столбец
row    = строка
value  = значение
6. Первичный ключ — PRIMARY KEY

Посмотри на нашу таблицу:

id | name  | age
---+-------+----
1  | Alex  | 25
2  | Ivan  | 31
3  | Maria | 22

У каждого пользователя есть уникальный id.

Это позволяет однозначно определить пользователя.

Например:

id = 1

означает конкретного пользователя.

Такой столбец обычно делают первичным ключом:

PRIMARY KEY

Например:

CREATE TABLE users (
    id INTEGER PRIMARY KEY,
    name TEXT,
    age INTEGER
);

Пока не переживай из-за CREATE TABLE. Мы подробно разберём его позже.

Главное сейчас:

PRIMARY KEY идентифицирует строку однозначно.

sql_training

Здесь:

говорит:

А:

означает:

Создай столбец id, который содержит целые числа и является первичным ключом.

name TEXT

— текстовое имя.

age INTEGER

— возраст как целое число.

city TEXT

— город.

9. Первый настоящий SQL-запрос

Теперь напишем:

SELECT *
FROM users;

Разберём буквально каждую часть.

SELECT

Говорит:

Что получить?

*

Означает:

Все столбцы.

FROM

Говорит:

Из какой таблицы?

users

Название таблицы.

Получается:

SELECT *
FROM users;
  │
  └── взять всё
      из users
10. SELECT конкретных столбцов

Нам не обязательно получать всё.

Например:

SELECT name
FROM users;

Получим:

Alex
Ivan
Maria
John
Anna

Или:

SELECT name, age
FROM users;

Получим:

name  | age
------+----
Alex  | 25
Ivan  | 31
Maria | 22
John  | 28
Anna  | 35

То есть:

SELECT name, age

означает:

Верни только name и age.

11. WHERE — фильтрация

Теперь самое интересное.

Допустим:

Покажи пользователей старше 25 лет.

SELECT *
FROM users
WHERE age > 25;

Результат:

id | name | age | city
---+------+-----+-------
2  | Ivan | 31  | Kazan
4  | John | 28  | Berlin
5  | Anna | 35  | Kazan

WHERE отвечает за фильтрацию строк.

Можно представить:

users
  ↓
WHERE age > 25
  ↓
подходящие строки
12. Условия

Например:

WHERE age = 25

Возраст равен 25.

WHERE age > 25

Старше 25.

WHERE age >= 25

25 или старше.

WHERE age < 25

Младше 25.

WHERE age <= 25

25 или младше.

А неравенство можно написать:

WHERE age <> 25

или:

WHERE age != 25

В PostgreSQL оба варианта работают.

13. Текстовые значения

Посмотрим:

SELECT *
FROM users
WHERE city = 'Moscow';

Обрати внимание:

'Moscow'

заключён в одинарные кавычки.

Для SQL это текстовое значение.

Результат:

Alex
Maria
14. AND

Можно поставить несколько условий.

Например:

Пользователи старше 25 лет из Казани.

SELECT *
FROM users
WHERE age > 25
  AND city = 'Kazan';

Обе проверки должны быть истинными.

15. OR

Например:

Пользователи из Москвы или Казани.

SELECT *
FROM users
WHERE city = 'Moscow'
   OR city = 'Kazan';

Достаточно выполнения хотя бы одного условия.

16. ORDER BY

Теперь предположим:

Покажи пользователей от самых молодых к самым старшим.

SELECT *
FROM users
ORDER BY age ASC;

ASC означает:

по возрастанию.

Можно написать:

ORDER BY age DESC;

DESC:

по убыванию.

Получим:

Anna   35
Ivan   31
John   28
Alex   25
Maria  22
17. LIMIT

Допустим:

Покажи двух самых старших пользователей.

SELECT *
FROM users
ORDER BY age DESC
LIMIT 2;

Получим:

Anna | 35
Ivan | 31

Очень важно понимать порядок мысли:

users
   ↓
ORDER BY age DESC
   ↓
самые старшие сверху
   ↓
LIMIT 2
   ↓
оставляем первых двух

🧠 19. Очень важная концепция

Сейчас тебе нужно запомнить не столько синтаксис, сколько роли основных конструкций:

Конструкция	Что делает
SELECT	Какие данные получить
FROM	Из какой таблицы
WHERE	Какие строки оставить
ORDER BY	Как отсортировать
LIMIT	Сколько строк вернуть

Попробуй воспринимать SQL как конструктор:

SELECT ...
FROM ...
WHERE ...
ORDER BY ...
LIMIT ...;
⚠️ 20. Порядок написания запроса

Обычно мы пишем:

SELECT
FROM
WHERE
ORDER BY
LIMIT

Например:

SELECT name, age
FROM users
WHERE age >= 25
ORDER BY age DESC
LIMIT 3;

Но есть интересный момент.

База данных концептуально обрабатывает запрос не совсем в этом порядке.

Условно можно думать:

FROM
  ↓
WHERE
  ↓
SELECT
  ↓
ORDER BY
  ↓
LIMIT

Это будет очень важно дальше, когда начнём разбираться с GROUP BY, HAVING, JOIN и оконными функциями.

Пока просто держи эту мысль в голове.
